Firebase instellen

1. Ga naar console.firebase.google.com

2. Klik Project toevoegen → geef het een naam

3. Klik Firestore Database → Maak database → testmodus

4. Projectinstellingen ⚙️ → Jouw apps → Webapplicatie </>

5. Kopieer projectId en apiKey en plak ze in de app

⚠️ Testmodus verloopt na 30 dagen!

Zet permanente regels in Firestore → Rules tab:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Plak bovenstaande → klik Publiceren. Sync werkt dan permanent.
